Appearance

How the request table and the component tree look.

Masked headers

One header name per line. Names matching token|secret|api-key are always masked. Masking applies on screen and to Copy as cURL / fetch, HAR, Postman and test-stub exports, which also blank the values of query parameters with such names (bodies are exported as captured); copying a single header copies its real value.

Quick-copy headers

One request header name per line. Each gets a one-click entry in the request's Copy menu and in the toolbar (from the latest request that has it).

Duplicate window

A repeat of an identical GET or HEAD request sent within this many milliseconds of the first finishing (or while it is still in flight) is flagged as a Duplicate.

ms

Open in editor

Per origin: the absolute path of the workspace the app is built from (component source paths are relative to it) and the editor to open. "Open in editor" is hidden for origins without a project root.
